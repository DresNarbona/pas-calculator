## 🏥 ¿Qué es?

Una **herramienta profesional web** para evaluación, predicción y manejo de acretismo placentario (PAS) que integra:

✅ **Scoring automático** de factores de riesgo obstétricos  
✅ **Modelos predictivos SMFM/FIGO** validados científicamente  
✅ **Análisis IA con Claude** para predicción avanzada  
✅ **Estimación dinámica de sangrado** perioperatorio  
✅ **Generación de PDF** profesionales automáticos  
✅ **Interfaz mobile-responsive** (funciona en cualquier dispositivo)  
✅ **Totalmente gratis** y personalizable

## 📋 Cómo Usar en 5 Pasos

### 1️⃣ **Factores de Riesgo**
Marca los antecedentes presentes:
- Cesáreas previas
- Placenta previa
- Legrado uterino
- Edad avanzada
- FIV, endometriosis, etc.

### 2️⃣ **Hallazgos Ecográficos**
Ingresa lo que ves en ecografía:
- Lacunas placentarias
- Pérdida de zona clara
- Vasos anómalos
- Grosor miometrial residual
- Score vascularización

### 3️⃣ **Estimación Sangrado**
Ajusta parámetros:
- Hemoglobina preoperatoria
- Plaquetas
- Grado FIGO estimado

### 4️⃣ **Análisis IA** (Opcional)
Haz clic "Analizar con IA" para:
- Predicción de invasión
- Riesgo de histerectomía
- Recomendaciones quirúrgicas

### 5️⃣ **Descargar Informe**
Genera PDF con:
- Resumen clínico
- Recomendaciones
- Preparación quirúrgica

## 🔑 Para Análisis IA (Opcional)

Si quieres usar análisis con Claude IA:

1. Registrate gratis en: https://console.anthropic.com/
2. Crea una **clave API**
3. En la calculadora, pestaña "Análisis Predictivo IA"
4. Pega tu clave
5. ¡Listo! Análisis automático

**Nota:** No es obligatorio. La calculadora funciona perfectamente sin IA.

## 🔧 Para Desarrolladores

### Personalizar la Calculadora

```html
<!-- Cambiar logo -->
<div class="logo-icon">🏥</div>  <!-- Cambiar emoji -->

<!-- Cambiar colores -->
:root {
  --primary: #1e40af;      <!-- Azul principal -->
  --success: #10b981;      <!-- Verde -->
  --danger: #ef4444;       <!-- Rojo -->
}

<!-- Agregar factores de riesgo -->
<div class="checkbox-item">
  <input type="checkbox" id="tuFactorNuevo">
  <label for="tuFactorNuevo">Tu factor de riesgo</label>
</div>
```

### Integración con tu EMR

```javascript
// Pasar datos desde FileMaker/tu sistema
const caseData = {
  patient_name: 'YADELIS GONZALEZ VALLE',
  age: 38,
  gestational_weeks: 32,
  risk_factors: {...}
};

// Guardar en navegador
localStorage.setItem('currentPatient', JSON.stringify(caseData));

// Recargar calculadora
window.location.reload();
```

### Usar Helper IA

```javascript
// Incluir librería
<script src="pas_api_helper.js"></script>

// Usar clase PASAnalyzer
const analyzer = new PASAnalyzer('tu-api-key');
const result = await analyzer.analyzeCase(caseData, 'invasion');
```
