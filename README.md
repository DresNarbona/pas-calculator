# PAS Risk Calculator · Prototipo científico orientativo

Herramienta web estática para estructurar la evaluación de sospecha de Placenta Accreta Spectrum (PAS).

## Uso previsto

Esta calculadora no contiene datos de pacientes precargados. Está diseñada como herramienta de apoyo docente y de estructuración clínica. No sustituye el juicio clínico experto ni constituye un modelo validado externamente como herramienta única de decisión.

## Estructura

1. Riesgo clínico-obstétrico.
2. Marcadores ecográficos principales.
3. Score transvaginal simplificado 0–9.
4. Preparación perioperatoria orientativa.
5. Informe automático no identificativo.

## Referencias conceptuales

- Placenta Accreta Index / Rac et al.
- Sistemas de puntuación ecográfica / Tovbin et al.
- Modelos ecográficos estandarizados / Sargent, Collins et al.
- Score transvaginal para severidad y pérdida hemática / Agarwal et al.

## Privacidad

No subir nunca datos reales de pacientes, números de historia clínica, nombres, fechas exactas o documentos clínicos identificativos al repositorio.
